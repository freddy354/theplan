An entry for the make.fun bounty [the-plan-make-fun-will-carry-20261122-2138](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138): a program that writes one plan an AI agent can carry out itself to turn $100 into the most money in 30 days. The plan: find Shopify stores with broken checkouts, email each a free audit naming the exact lost sale, and sell the $49 fix — code the agent writes itself. At a 5% close rate, 10 fixes hold $490 by day 30.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
